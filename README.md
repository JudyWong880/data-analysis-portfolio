## 项目列表 (Project Showcase)

以下是本作品集包含的主要项目，点击文件夹可查看详细代码与分析报告。

Here is a list of the main projects included in this portfolio. Click on the folders to view the detailed code and analysis reports.

### 📈 市场与商业分析 (Market & Business Analysis)

* **[Olist_Growth_Analysis](./Olist_Growth_Analysis/)** & **[Olist_Logistics_Analysis](./Olist_Logistics_Analysis/)**
    * **内容 (About):** 针对巴西最大的电商平台 Olist 的深度分析。包含了增长黑客 (Growth Hacking) 策略分析，以及物流瓶颈 (Logistics Bottleneck) 的探讨。
    * **技术栈 (Tech):** Python (Pandas, Matplotlib, Seaborn), Jupyter Notebook, Folium (地理热力图)。
    * **亮点 (Highlights):** 产出了客户需求地理热力图、供需分布地图等交互式图表。

* **[Sales_Forecasting_Project](./Sales_Forecasting_Project/)**
    * **内容 (About):** 应用时间序列分析模型，对销售数据进行预测，帮助企业进行库存管理与运营规划。
    * **技术栈 (Tech):** Python, Scikit-learn, Statsmodels, Jupyter Notebook。

* **[China_Portfolio_BI_Analysis](./China_Portfolio_BI_Analysis/)**
    * **内容 (About):** 针对中国市场的投资组合进行商业智能分析。通过 Python 爬取股价数据，并使用 Power BI 进行仪表板设计。
    * **技术栈 (Tech):** Python (akshare), Power BI。
    * **亮点 (Highlights):** 包含多个 `.pbix` 报表文件，展示了 BI 报表设计能力。

### 🎮 游戏产业分析 (Gaming Industry Analysis)

* **[League-of-Legends](./League-of-Legends/)**
    * **内容 (About):** 英雄联盟 (League of Legends) 游戏数据分析，探讨游戏内指标与胜负的关联性。
    * **技术栈 (Tech):** Python, Jupyter Notebook。

* **[PUBG](./PUBG/)**
    * **内容 (About):** 绝地求生 (PUBG) 游戏数据分析，通过玩家行为数据挖掘致胜关键。
    * **技术栈 (Tech):** Python, Jupyter Notebook。

* **[Steam](./Steam/)**
    * **内容 (About):** 对 Steam 平台上的游戏数据进行分析，可能包含市场趋势、玩家偏好等。
    * **技术栈 (Tech):** Python, Jupyter Notebook。

### 💹 金融与投资研究 (Finance & Investment Research)

* **[NVIDIA_Equity_Research_Analysis](./NVIDIA_Equity_Research_Analysis/)**
    * **内容 (About):** 针对半导体巨头 NVIDIA (英伟达) 的股票研究分析。使用 Python 自动获取每日股价数据并进行分析。
    * **技术栈 (Tech):** Python (akshare), Pandas, Excel。

* **[Web3_RWA_Research_Report](./Web3_RWA_Research_Report/)** & **[Web3_ZRO_Launch_Analysis](./Web3_ZRO_Launch_Analysis/)**
    * **内容 (About):** Web3 领域的专题研究，包含了真实世界资产 (RWA) 报告以及 ZRO 代币发行的分析。

* **[DeFi_Nexus_Swap_GTM_Strategy](./DeFi_Nexus_Swap_GTM_Strategy/)**
    * **内容 (About):** 为去中心化金融 (DeFi) 产品 Nexus Swap 设计市场进入 (Go-To-Market) 策略，并进行用户体验分析。

## 🚀 如何使用 (Usage)

1.  **克隆代码仓库:**
    ```bash
    git clone [https://github.com/JudyWong880/data-analysis-portfolio.git](https://github.com/JudyWong880/data-analysis-portfolio.git)
    ```
2.  进入特定项目文件夹查看代码与相关文件。
    ```bash
    cd [Project-Folder-Name]
    ```
3.  若为 `.ipynb` 文件，请使用 Jupyter Notebook 或 VS Code 打开。
4.  若为 `.pbix` 文件，请使用 Microsoft Power BI Desktop 打开。
